# MG / Componente / Aviso importante

Destaca una información operativa que no se puede pasar por alto.

**Variantes:** Amarillo sobre línea oscura · Negro sobre línea amarilla · Con ícono alerta, info o grupo.

**Campos editables:** Ícono, título, texto.

**Largo recomendado:** Título máx. 30 · Texto máx. 120.

**Reglas de combinación:** Uno por pieza. No se usa para promociones. Si todo es importante, nada lo es.

**En código:** `MG.aviso({ titulo, texto, icono: 'alerta'|'info'|'grupo' })`
