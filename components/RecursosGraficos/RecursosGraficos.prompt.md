# MG / Fundamentos / Recursos gráficos

Franja lateral, separador barra, barra inclinada, trama, reglas, etiquetas y numeradores.

Cuándo usarlos: franja → línea Oscuro con franja (educación, carruseles, testimonios); separador barra → cerrar un título de campaña o portada; barra inclinada → solo campaña, una por pieza; trama → solo en la versión sin foto; etiquetas → una categoría por pieza. Para no sobrecargar: máximo dos recursos además del logo, y nunca un recurso detrás de un texto que hay que leer.
