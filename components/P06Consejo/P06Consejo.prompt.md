# MG / Plantilla / Consejo

Consejo de entrenamiento con número gigante. Variante Mito / realidad.

**Objetivo:** Educar. **Nivel de intensidad:** Comunidad y educación.

**Formatos:** plantilla maestra en Feed vertical 1080 × 1350; adaptaciones reacomodadas a Feed cuadrado 1080 × 1080 e Historia / portada 1080 × 1920.

**Campos editables:** Número, título, texto, firma · Mito, realidad. Instagram, WhatsApp y dirección se cargan una vez en el Estudio MG.

**Cómo editarla:** Estudio MG → Plantilla “06 · …” → Textos → Descargar PNG. Nombre de archivo: `MG_Plantilla_…_FeedVertical_….png`.

**En código:** `MG.render('consejo', 'v'|'s'|'h', { linea, datos, conFoto, foto, variante, slide })`
