# MG / Componente / Tarjeta de actividad

Resume una clase o actividad dentro de un panel: etiqueta, nombre, texto breve y datos.

**Variantes:** Sobre negro (panel gris) · Sobre amarillo (panel negro).

**Campos editables:** Etiqueta, título, texto, datos.

**Largo recomendado:** Título máx. 20 · Texto máx. 90 · Hasta 2 datos.

**Reglas de combinación:** Hasta 2 tarjetas por pieza (en 4:5, apiladas). Para 3 o más actividades, usá la tabla o un carrusel.

**En código:** `MG.tarjetaActividad({ etiqueta, titulo, texto, datos })`
