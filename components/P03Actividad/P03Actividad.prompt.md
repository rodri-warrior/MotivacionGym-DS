# MG / Plantilla / Actividad

Presentación de una actividad. Foto arriba (4:5, 9:16) o al costado (1:1), título, bajada, datos y CTA.

**Objetivo:** Generar consultas. **Nivel de intensidad:** Comunidad y educación.

**Formatos:** plantilla maestra en Feed vertical 1080 × 1350; adaptaciones reacomodadas a Feed cuadrado 1080 × 1080 e Historia / portada 1080 × 1920.

**Campos editables:** Título, bajada, 2 datos, CTA, foto o palabra para la versión sin foto. Instagram, WhatsApp y dirección se cargan una vez en el Estudio MG.

**Cómo editarla:** Estudio MG → Plantilla “03 · …” → Textos → Descargar PNG. Nombre de archivo: `MG_Plantilla_…_FeedVertical_….png`.

**En código:** `MG.render('actividad', 'v'|'s'|'h', { linea, datos, conFoto, foto, variante, slide })`
