# MG / Fundamentos / Tipografía

Bebas Neue para títulos en MAYÚSCULAS, Barlow Condensed para subtítulos, etiquetas y datos, Barlow para lectura. 12 estilos calculados para leerse en un teléfono.

Reglas: un título por pieza; máximo 1–2 palabras destacadas; el título puede bajar un solo paso de la escala para que entre una palabra larga; piso absoluto 26 px solo para letra chica. Si el texto no entra: acortá, pasá detalle a la descripción o dividí en carrusel.
