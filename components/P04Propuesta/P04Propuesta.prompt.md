# MG / Plantilla / Propuesta

Propuesta comercial o promoción. Título grande, bloque de precio opcional, CTA y letra chica de condiciones.

**Objetivo:** Generar consultas. **Nivel de intensidad:** Campaña.

**Formatos:** plantilla maestra en Feed vertical 1080 × 1350; adaptaciones reacomodadas a Feed cuadrado 1080 × 1080 e Historia / portada 1080 × 1920.

**Campos editables:** Título, detalle, [PRECIO], [CONDICIONES], [VIGENCIA], CTA. Opción: ocultar precio. Instagram, WhatsApp y dirección se cargan una vez en el Estudio MG.

**Cómo editarla:** Estudio MG → Plantilla “04 · …” → Textos → Descargar PNG. Nombre de archivo: `MG_Plantilla_…_FeedVertical_….png`.

**En código:** `MG.render('promo', 'v'|'s'|'h', { linea, datos, conFoto, foto, variante, slide })`
