Logo de Motivación Gym vectorizado a partir del PNG original (trazado, sin redibujar). `mg-logo-blanco` para fondos negros y grises; `mg-logo-negro` para amarillo; `mg-logo-amarillo` solo sobre negro y como alternativa puntual.
